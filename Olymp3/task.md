# Рандомный деплой
«Давай просто подбросим монетку, у меня уже нет сил спорить», - уставший бэкендер предложил фронтендеру радикальный способ выбрать дизайн главной страницы. Они решили провести серию из N бросков. Если решка выпадет хотя бы М раз, они оставят вариант с тёмно-синим футером, иначе - сделают всё в лайт-киберпанке. 
Пока монета летает в воздухе, DevOps-инженер решил посчитать, сколько вообще существует различных сценариев бросков, при которых бэкендер одержит победу и отстоит свой любимый тёмный интерфейс.

### Формат входных данных
Единственная строка содержит два целых числа: N - общее количество бросков монетки, и М - минимальное число решек для победы бэкендера (1 s N s 20, 0 s M s N).

### Формат результата
Выведите одно целое число - точное количество выигрышных последовательностей бросков.

**Примеры**
Входные данные
```
3 2
```

Результат работы
```
4
```
