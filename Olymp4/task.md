# Кибератака
«Красный код! База данных под атакой, логика деплоя изолирована!» - сирена в отделе кибербезопасности StartCoding застала дежурных врасплох. На экране мониторинга оперативная память сервера сейчас выглядит как квадратная сетка размером N x N ячеек, и в К узлах хакеры уже активировали опасный эксплойт.
Каждую секунду вредоносный софт расползается из зараженных ячеек во все 8 соседних секторов (по горизонтали, вертикали и диагоналям). Чтобы локализовать угрозу и спасти проекты студентов, админам нужна точная карта распространения. Помогите им рассчитать, через сколько секунд вирус впервые проникнет в каждую конкретную ячейку памяти.

### Формат входных данных
Первая строка содержит два целых числа: размер сетки памяти N (1 s N s 1000) и количество стартовых точек заражения К (1 s K s 10^5). Следующие К строк содержат координаты очагов (xi, yi) через пробел (1 s xi, yi s N) - номера строки и столбца.

### Формат результата
Выведите матрицу размера N x N, где на пересечении і-й строки и ј-го столбца стоит число - время (в секундах) заражения этой ячейки. Элементы в строках разделяйте одиночными пробелами.

**Примеры**
Входные данные
```
3 1
2 2
```

Результат работы
```
1 1 1
1 0 1
1 1 1
```
