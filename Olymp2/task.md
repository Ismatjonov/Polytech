# Хакатон в StartCoding
На хакатоне по фронтенду в StartCoding команды выстроили свои ноутбуки в один длинный ряд. Каждый ноутбук потребляет определенное количество ватт. Организаторы
выделили несколько сетевых фильтров, но у каждого из них есть строгое ограничение: суммарная мощность непрерывно подключенного ряда ноутбуков не должна превышать S
ватт, иначе выбьет пробки.

Ментору стало интересно, сколько существует способов выбрать непрерывный отрезок ноутбуков от позиции I до г включительно, чтобы их общая нагрузка была безопасной (не
больше S). Помогите организаторам найти количество таких безопасных отрезков.

### Формат входных данных
Первая строка содержит два целых числа: N - количество ноутбуков в ряду, и S - максимально допустимая нагрузка в ваттах (1 s N s 10^5, 1 s S s 10^18). Вторая строка содержит N
целых чисел Ai (1 s Ai s 10^9) - энергопотребление каждого ноутбука.

### Формат результата
Выведите одно целое число - общее количество подходящих непрерывных отрезков.
### Примеры
**Входные данные**
```
7 20
2 5 6 10 3 4 11
```

Результат работы

```
17
```
